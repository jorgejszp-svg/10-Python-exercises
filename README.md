# Ejercicios Básicos de Python

Este repositorio contiene una colección de scripts sencillos en Python desarrollados para practicar operaciones matemáticas básicas, lógica de negocio, manejo de tipos de datos, conversiones y formateo de texto mediante la terminal.

## Requisitos Previos

- Tener instalado **Python (versión 3.x)** en tu sistema.
- Una terminal activa (CMD, PowerShell o la terminal integrada de tu editor como VS Code).
